# 2026-06-12

## OpenSpec-Change `offer-edit-and-finalize` durchgezogen

Full Lifecycle proposal → design → specs (5 Files) → tasks.md. Schema `spec-driven`, complete + `openspec validate` grün.

Wichtigste Design-Entscheidungen (Details in `openspec/changes/offer-edit-and-finalize/design.md`):

- **3-Felder-Gruppen-Modell** statt einzelner Per-Feld-Edit-Flags: contract-derived (re-create überschreibt) / user-editable (re-create preserved) / immutable identity. Single source via `OfferRecord._contract_derived_fields()` Classmethod. Macht re-create-Semantik testbar statt implizit.

- **Lock-Enforcement zentral via `OfferService._guard_writable`**, nicht via Django-Signals. Alle Mutations rufen den Guard inside `select_for_update` als erstes auf. Raises `OfferLockedError`, GraphQL-Layer mapped es zu typed result. Race-safe via Row-Lock.

- **`ContractAttachment.source_offer` FK statt synthetic** (User-Direktive). Anders als das OC-Pattern (Diary 2026-05-13 mit negativer ID). Bytes kopiert, nicht Referenz — Attachment überlebt Offer-Delete via `SET_NULL`. Mehrere `category=offer` Rows pro Contract erlaubt (Audit-Trail bei Clone-to-Edit).

- **Markdown via `markdown` + `bleach`-Allowlist**: nur block-level (p/em/strong/ul/ol/li/code/blockquote/h3/h4). Kein `<a>`, `<img>`, `<style>`, `<script>`. WeasyPrint rendert das sicher in PDF.

- **Neue Permission `offers.finalize`** separat von `offers.write` — gezielt damit Finance-Reviewer Locks setzen kann ohne Edit-Recht.

- **Lifecycle vereinfacht**: `draft → sent | finalized`. `accepted/rejected/cancelled/expired` (existing choices) bleiben für DB-backwards-compat lesbar, neue Transitions raus. `sent` system-driven (nach erfolgreichem `email_sent_at`), `finalized` user-driven.

- **Min-term/notice-period**: aus `contract.min_duration_months` + `contract.notice_period_months` initial snapshotted, user-overridable, conditional render im PDF (nur wenn > 0). Existing Felder am Contract waren bereits da.

User-Klärungen (kritisch für Spec-Korrektheit):
- Gate: nur `status === 'draft'` für Create-Button, NICHT alle non-active
- Lock-Trigger: nach `email_sent_at`, nicht beim Send-Click
- Re-create preserves User-Edits
- `sent` = system, `finalized` = user
- Markdown ja, 2 Felder (after items + before terms)
- Min-term wording: "Mindestlaufzeit XX Monate ab Vertragsbeginn", "Kündigungsfrist YY Monate zum Ende der Mindestvertragslaufzeit"
