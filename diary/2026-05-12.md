## Integrations/API-Tab für alle User sichtbar

**Problem**: McpSettings (persönliche API-Keys für MCP-Zugriff) waren hinter `settings.read` Permission versteckt. Nicht-Admins konnten ihre eigenen Keys nicht verwalten.

**Fix**:
- **Frontend**: Integrations-Tab in `SettingsLayout` ohne Permission-Gate gerendert. In `IntegrationSettingsTabs` werden tenant-weite Sub-Tabs (HubSpot/TimeTracking/Email/Notifications) weiterhin per `canManageIntegrations` (settings.read) ausgeblendet, **API-Sub-Tab bleibt aber für alle sichtbar**. Default-Sub-Tab für Non-Admins: `api`.
- **Backend**: `api_keys`, `generate_api_key`, `revoke_api_key` von `settings.read/write` auf reinen `get_current_user(info)` umgestellt. Begründung: API-Keys sind per-User (FK auf user). Validation: requested_permissions müssen Subset der eigenen User-Permissions sein (line 2669) — verhindert Privilege Escalation.

## MCP verbose-Flag + GraphQL-Schema-Endpoint

User-Request: alle Felder per MCP exposed (z.B. AB-Nummer). Diskussion ergab: MCP optimiert für LLM (Text/Markdown), für strukturierten Programmatic-Zugriff existiert bereits GraphQL — kein REST nötig. API-Keys funktionieren in beiden (`X-API-Key`-Header).

**(a) MCP verbose=True**: `_BaseTool._dump_all_fields()` Helper iteriert `obj._meta.get_fields()`, skipt M2M/Reverse-Relations, FK als `*_id`. Parameter `verbose: bool = False` an `get_contract`, `get_customer`, `get_product`, `get_invoice`, `get_transaction`. Plus AB-Nummer + Offer-Number + PO + NetSuite-SO unconditional im `get_contract`-Default.

**(b) GraphQL-Doku im API-Tab**: neue Section in `McpSettings.tsx` zeigt Endpoint (`/graphql`), SDL-Link (`/graphql/schema.graphql`), curl-Beispiel mit `X-API-Key`, Introspection-Hinweis.

**(c) Schema-Dump**: 
- Neuer Management-Command `export_graphql_schema` schreibt SDL (80k chars) nach `backend/schema.graphql`
- Public View `GraphQLSchemaView` in `core/version_views.py` liefert SDL als `text/plain`, fallback auf live `schema.as_str()` wenn file fehlt
- URL `/graphql/schema.graphql` ohne Auth (Schema ist Source-of-Truth, kein Geheimnis)
